# not_enough_asserts

Library for convenient assertions in Rust tests.

Documentation: https://docs.rs/not_enough_asserts/

# Minimum Supported Rust Version (MSRV)

`not_enough_asserts` is supported on Rust 1.85.1 and higher. `not_enough_asserts`'s MSRV will not be changed in the
future without bumping the major or minor version.
